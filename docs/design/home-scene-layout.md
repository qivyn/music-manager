# 猫咪首页 · 布局与入口原型

本轮用于确认实际窗口中的构图、播放区与入口。月夜与奶油两个主题均有猫咪呼吸、偶尔的尾尖轻摆和点击轻蹭，点击时伴随小爱心反馈。

## 两个主题

- **奶油留白**：`奶油留白里的酣睡白猫.png`，暖纸白、灰粉与奶油色。
- **月夜打盹**：`月夜里打盹的猫咪.png`，烟蓝、灰紫与暖米色。

原图保留在本目录，完整副本位于 `frontend/assets/home-cat-{cream,night}.png`。右上角独立的外观按钮沿用最初半明半暗的圆形图标，点击直接切换两个主题，选择保存在本机；悬停提示表示即将切换的外观。旁边齿轮按钮打开设置菜单，保留微动效、快捷键与检查更新。旧版 archive / sky 的选择分别迁移到 cream / night。

手动切换外观时先准备目标插画与背景，再进行 520ms 的柔和叠化；启动恢复主题不播放过渡。支持 View Transition 的窗口统一叠化整页，旧版 WebView 使用颜色渐变与不接收点击的旧插画叠层。切换中不叠加连续点击，结束后清理叠层；系统减少动态效果或窗口隐藏时直接切换。音频元素不被替换。相关检查：`node --test scripts/test-theme-transition.cjs`，覆盖图片就绪、连点、过渡取消、兼容路径及清理。

## 内页配色

音乐库、片段、专辑、最近播放以及详情、导入、裁剪、设置弹窗统一使用 `frontend/themes.css`。加载顺序为基础结构 `style.css` → 主题 `themes.css` → 首页场景 `home-scene.css`，首页原画、场景色与互动区域单独保留。

- 两个主题的内页直接复用首页各自的手绘空背景；顶栏、侧栏与工具栏透明，内容面板使用同色系的实色，保证文字易读。主背景、正文和主按钮颜色引用首页的 `--home-paper`、`--home-ink`、`--home-accent`，不另设偏离原画的灰蓝色系。
- 奶油：原画的暖纸白底、奶油沙发色面板、灰粉按钮和淡紫标签。封面占位图取沙发与地毯的浅杏、灰粉、淡紫。
- 月夜：原画的蓝紫底，面板取较明亮的蓝紫笔触，沙发暖光的奶油色用于主按钮，地毯的淡紫色用于标签与选中状态。保留较淡的分区边界和轻阴影，使蓝紫与暖奶油色相互平衡。
- 普通、悬停、选中、播放、禁用状态分别设置配色。候选采用低饱和琥珀色，删除采用柔和红色；播放器、波形、输入框与提示同属对应主题。弱化旧版亮面扫光、厚重投影和高饱和封面占位图。
- 波形使用独立的实色：奶油主题为灰粉色轮廓、深玫瑰色进度，月夜主题为淡紫色轮廓、暖奶油色进度。普通、悬停、选中与播放器背景上的波形对比度至少为 3:1；切换主题时列表与暂停中的播放器同步重绘，不重新解码音频。

共享颜色集中为语义变量，`--on-primary` 独立定义主按钮文字，避免深色主题复用白字。主题设置 `color-scheme`，使原生选择框和表单控件同步明暗。静态检查覆盖主要文字／背景组合的对比度；实际显示仍需在窗口中确认。

## 布局

背景与场景分别适配：两张移除物件后生成的手绘空背景铺满窗口；原始插画仍按比例完整放在右下方，画板宽度不超过窗口宽度、可容纳的高度与 1240px 三者的最小值。这样加宽窗口只增加背景空间，猫咪、沙发和地毯不会为了铺满而持续放大或被裁切。

原图只有上方 22% 与左侧 28% 的空背景区域渐变衔接到对应手绘底图，所有物件保留原图画风和不透明度。点击区域继续跟随同一画板缩放。高窗口将播放信息移向上方。背景素材、内置图像编辑方式和完整 prompt 记录在 `home-background-plates-v1.prompt.txt`。

左侧为歌曲名、作者/专辑、上一首、播放、下一首与进度条。空库显示导入入口。首页隐藏底部重复播放器和文字导航，进入音乐库后恢复原有导航，可继续访问专辑。

## 待体验确认的入口

| 物件 | 行为 |
| --- | --- |
| 沙发 | 音乐库（全部音乐） |
| 地毯露出的区域 | 最近播放，使用已有播放历史 |
| 毛线球 | 音乐片段 |
| 猫咪 | 摸摸互动：轻蹭、尾尖回应与小爱心反馈 |

沙发、地毯和毛线球在悬停或键盘聚焦时显示入口名称；右上角问号可以同时显示/收起这些提示。猫咪不显示文字气泡，直接通过动作和小爱心回应，保留按钮的无障碍名称。底部引导可关闭并记住选择。猫咪和毛线球的点击优先于下方沙发和地毯。Tab 可访问入口，Enter/空格激活；首页空白处按空格播放，按 `/` 进入曲库搜索。

悬停保留较淡的羽化柔光，叠层不透明度约为 7.1%，为最初柔光强度的二分之一；边缘在独立显示层中模糊，避免直接露出多边形尖角。实际按钮始终透明，并使用手形光标及入口文字提示表示可点击。动效开启时柔光短暂淡入淡出，关闭或系统减少动态效果时直接切换。键盘聚焦时使用相同柔光强度，导航入口提示带描边，猫咪头部上方显示一个小圆环标记；鼠标悬停不会显示猫咪标记或文字气泡。

## 双主题微动效样片

保留选定原画，不替换猫咪或沙发。`frontend/home-scene-motion.js` 使用原图纹理，在覆盖头部、躯干与尾尖的局部区域叠加网格变形。两张图分别定义动作区域、头颈支点与尾巴弯曲方向，共用渲染器、呼吸节奏和互动时序。呼吸与尾尖使用互不重叠的权重区域，爪子、尾根与补片边缘固定；头部只在点击互动时轻蹭，平时不动。

| 主题 | 原图局部区域 | 动作方向 |
| --- | --- | --- |
| 月夜打盹 | 左上角 (976, 500)，516×400 像素 | 头向左侧扶手轻蹭，右侧尾尖摆动 |
| 奶油留白 | 左上角 (864, 368)，576×392 像素 | 头向右侧扶手轻蹭，左侧弯曲尾尖摆动；单独固定胸前的两只爪子 |

呼吸周期为 8 秒，约 2.7 秒吸气、4.6 秒呼气，随后停顿约 0.6 秒；最大抬升 4 原图像素，在 900–1240px 画板中约为 2.3–3.1px。背部轮廓保留略宽的活动范围，用缓慢、浅幅的起伏表现熟睡感。

尾尖首次在进入首页约 2.6 秒后开始轻摆，持续约 3 秒：先向一侧缓缓弯曲，再带一点回弹归位。后续间隔、方向与幅度有变化，大部分时间静止，不与每次呼吸同步。最大横向位移为 12 原图像素，在 900–1240px 画板中约为 6.8–9.4px；弯曲从悬垂尾巴中下段逐渐增强，尾根不动。

点击猫咪时，头部轻轻向扶手靠拢、短暂停留再放松，尾尖同时做一次柔和回应，头顶浮起一颗细线爱心。整段回应约 2.4 秒，期间的重复点击不重启、不排队，呼吸幅度和时钟保持不变。用户触发的尾巴动作与原有摆尾平滑混合，避免点击瞬间跳动。猫咪按钮仍可通过 Tab 聚焦、Enter/空格激活，屏幕阅读器会收到简短的摸摸反馈。原来的全局文字 toast 已移除。

当前仍是局部变形样片，头部与尾巴周围少量沙发笔触也会参与过渡；如果要做大幅摆尾、明显转头或伸懒腰，需要进一步处理独立图层和接触边界。

右上角设置中的「场景微动效」可关闭并记住选择。系统开启减少动态效果时停止动画，点击猫咪仅显示静态爱心。窗口隐藏时暂停猫咪动作，回来继续原来的姿态。三种猫咪动作共用一个画布、时钟与动画循环。切换主题、离开首页或重新渲染时释放动画帧、图形资源及爱心反馈定时器。图像加载或 WebGL 失败时直接显示原始静态插画，物件入口和爱心反馈仍然可用。

曾用内置 imagegen 试制空沙发与透明猫图层，但透明猫的大小、轮廓和位置发生变化，因此未接入。完整尝试 prompt 记录在 `home-night-breathing-v1.prompt.txt`，运行中的样片只引用已选定的原图，没有新增生成素材依赖。当前不包含自动脸颊蹭动与音乐粒子。

## 预览与检查

在仓库根目录运行 `python3 -m http.server 1430 --bind 127.0.0.1 --directory frontend`，打开 `http://127.0.0.1:1430/preview.html`。预览页使用示例曲目元数据，本地音频播放请在 Tauri 应用中体验。

建议在 1200×800、900×600 和宽窗口中确认：文字大小与留白、主体比例、物件提示位置，以及入口是否符合直觉。对两个主题分别检查，尤其注意猫咪朝向不同。

自动检查：`node --test scripts/test-home-audition.cjs scripts/test-home-scene.cjs scripts/test-home-scene-motion.cjs`。覆盖播放与切歌竞态、无唱机播放路径、两幅图的入口归属、两个主题各自的呼吸/尾尖/头部区域、尾巴静止间隔与回落连续性、最大形变下网格不翻折、点击轻蹭与摆尾混合、重复点击不叠加、主题切换及图片延迟加载时的姿势匹配、减少动态效果和静态降级；不替代实际窗口的视觉验收。

分别在两个主题中先以正常视距看进入后的前 6 秒，再观察约半分钟，并开关「场景微动效」对照。点击一次猫咪，再试连续点击，重点确认轻蹭方向、头颈衔接、爱心位置和尾尖回应是否自然，周围沙发笔触有无明显牵扯；静止时脸与爪子仍应稳定。交替切换主题，确保动作位置跟随对应原图。关闭动效时也应能收到静态的摸摸反馈。自动化浏览器受本地地址访问策略限制，调整后的实时渲染仍需视觉验收。
