### v0.2.11 · 更新更省心

- **自动发现新版本。** 启动后每天最多在后台检查一次；有新版本时右上角显示“有新版本”，设置按钮带一个小圆点。不弹窗、不自动下载。
- **一键更新。** 点击“更新到 x.y.z”即可下载，下载完成后确认一次“现在重启 / 稍后”。
- **更新过程更安静。** 应用内更新时安装器只显示进度窗口，完成后自动打开新版并关闭；只有失败时才显示恢复和诊断按钮。用 DMG 手动安装成功后，安装窗口也会自动关闭。
- **告诉你更新成功了。** 新版首次打开时提示“已更新到 x.y.z”，可直接查看本版更新内容。
- **旧安装窗口不再挡路。** 0.2.6 / 0.2.7 的安装窗口如果还开着并占用安装锁，更新程序会请它关闭（和点关闭按钮一样，正在安装的窗口不会被打断）；确实无法继续时，用普通用户能看懂的话说明怎么做。
- **失败时给出下一步。** 检查失败显示“重试检查”，签名问题显示“重新下载”，安装窗口冲突显示“已关闭，重试”，原因不明时优先“导出诊断信息”。

### 从旧版升级

- **0.2.10**：正常使用“检查更新 → 下载更新 → 重启并更新”。
- **0.2.6 / 0.2.7**：可直接检查并升级到本版本，在原位置更新。
- 更早版本没有应用内更新入口时，请下载本版 DMG，打开“安装与更新声场档案”，点击“安装 / 更新”。

### 音乐库和音频保持原位

数据库 schema 保持为 3。保留原 `settings.json` 和 `library.db` 路径，音乐、片段、标签、专辑标签及候选清单无需重新导入。安装器不搬迁音乐库、不修改原始音频、不随应用恢复而回滚数据库。移动硬盘未连接时等待重试，不创建替代空库。

### 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple Silicon Mac | `music-manager_{{version}}_aarch64.dmg` |
| Intel Mac | `music-manager_{{version}}_x64.dmg` |

打开对应 DMG，双击“安装与更新声场档案”，点击“安装 / 更新”，等待新版启动确认后窗口会自动关闭。只有当前账户不能写入安装位置时才需要管理员授权。应用和安装器使用 ad-hoc 签名，更新包使用独立数字签名；尚未进行 Apple Developer ID 签名或公证。若 macOS 首次阻止打开，可按系统提示在“隐私与安全性”中允许该应用。
