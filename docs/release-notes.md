### v0.2.10 · 原地更新，修复安装窗口阻塞更新

- **在原位置更新。** 首次安装放到 `/Applications/声场档案.app`；已有安装在原位置替换，不再搬迁到系统“应用程序”，也不删除其他位置的副本。应用内更新替换正在运行的那份；DMG 安装窗口依次选择未完成更新的位置、正在运行的副本、`/Applications`、`~/Applications`，并在窗口中显示安装位置。
- **只在需要时请求管理员密码。** 当前账户能写入安装目录时不再提权；安装记录只按用户保存在 `~/Library/Application Support/com.musicmanager.installer/user`。
- **修复安装窗口阻塞应用内更新。** 旧版安装窗口打开期间一直占用安装锁，应用内更新会在输入密码后才报“另一个安装窗口正在工作”。现在安装窗口只在操作期间占用锁，并在每次操作前重新读取安装记录；冲突在请求授权前检查，提示会说明是哪个窗口及其进程号。主应用退出前也会先检查。
- **诊断更有用。** 安装器初始化失败时，诊断 ZIP 包含正在运行的安装窗口列表。
- **更新确认更清楚。** 确认框改为“退出并安装更新？”，需要密码时提前说明；确认后才显示等待当前操作完成。

### 从旧版升级

- **0.2.8 / 0.2.9 已撤回**，请改用本版本。
- **0.2.6 / 0.2.7**：正常使用“检查更新 → 下载更新 → 重启并更新”，在原位置升级到 0.2.10。若仍打开着旧的“安装与更新声场档案”窗口，请先按 ⌘Q 退出它，否则旧窗口会继续占用安装锁。
- 更早版本没有应用内更新入口时，请下载本版 DMG，打开“安装与更新声场档案”，按提示保存并退出旧应用后继续。
- 其他位置有未完成的更新事务时，安装器会停止并提示先在该位置完成或恢复，不会通过删除记录绕过保护。

### 音乐库和音频保持原位

数据库 schema 保持为 3。保留原 `settings.json` 和 `library.db` 路径，音乐、片段、标签、专辑标签及候选清单无需重新导入。安装器不搬迁音乐库、不修改原始音频、不随应用恢复而回滚数据库。移动硬盘未连接时等待重试，不创建替代空库。

### 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple Silicon Mac | `music-manager_{{version}}_aarch64.dmg` |
| Intel Mac | `music-manager_{{version}}_x64.dmg` |

打开对应 DMG，双击“安装与更新声场档案”，点击“安装 / 更新”，按需完成管理员授权并等待新版启动确认。应用和安装器使用 ad-hoc 签名，更新包使用独立数字签名；尚未进行 Apple Developer ID 签名或公证。若 macOS 首次阻止打开，可按系统提示在“隐私与安全性”中允许该应用。
