### v0.2.12 · 记录电影使用，整理音乐更顺手

- **记录音乐用于哪些电影。** 音乐与电影按 ID 关联，每对只记录一次，备注独立保存在使用记录上。可从音乐侧搜索、勾选或新建电影，也可从电影侧分页批量选择已有音乐，支持跨页选择和统一备注；重复关联跳过且不覆盖已有备注，取消不会写入。
- **独立的电影目录。** 支持搜索、新建、改名、删除和使用备注编辑。同名片名按首尾空格、全半角及大小写归一化后复用，改名冲突时提示。删除电影会确认并清理其使用记录，保留音乐、片段和音频；移除关联也保留两侧记录。
- **更清楚的目录和列表。** 专辑与电影默认显示紧凑目录，进入详情后通过路径栏返回，保留搜索和页码。电影直接显示“修改／删除”，专辑直接显示“删除专辑”。电影标签采用随明暗主题变化的暖金色样式，长片名自然换行；普通 Tag 与电影关联支持确认后就地移除。
- **导入过程可掌握。** 显示扫描与导入进度，支持停止任务；已完成的音乐保留，其余文件可继续导入。重复音乐只显示跳过数量，保留待导入文件的编辑；关闭并重新打开导入窗口可继续处理草稿。
- **按需读取与稳定交互。** 音乐、片段、目录、候选和详情列表由 SQLite 筛选、排序和分页；波形进入可视区域附近才加载，并与播放器复用。音乐行悬停不再移动或改变高度，列表不再显示斜向扫光；Tag 筛选统一在侧栏，收起侧栏不影响顶部导航。暂时隐藏“最近”入口，保留播放历史。
- **修复切歌和筛选边界。** 从音乐列表播放最新 10 首以外的曲目后返回首页，上一首／下一首按全库位置正常工作，并保留播放进度。电影使用状态筛选不影响音乐片段页，返回音乐列表时保留原选择。

### 从旧版升级

- **0.2.11**：点击新版本提示或从设置检查更新，下载后选择重启安装。
- **0.2.6 / 0.2.7 / 0.2.10**：可通过应用内检查更新升级到本版本，在原位置更新。
- 更早版本没有应用内更新入口时，请下载本版 DMG，打开“安装与更新声场档案”，点击“安装 / 更新”。

### 音乐库和音频保持原位

本版数据库从 schema 3 升级到 **schema 4**，新增电影及使用记录。首次打开先生成完整 SQLite 备份，迁移在单个事务中完成，校验失败整体回滚。保留原 `settings.json` 和 `library.db` 路径，音乐、片段、标签、专辑标签、候选清单及播放历史无需重新导入，原始音频不变。

仅支持 schema 3 的旧客户端不能写入升级后的音乐库。恢复旧应用前需先检查数据库兼容性；安装器不会随应用恢复而回滚数据库，也不要直接用旧备份覆盖已经继续编辑过的库。移动硬盘未连接时等待重试，不创建替代空库。

### 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple Silicon Mac | `music-manager_{{version}}_aarch64.dmg` |
| Intel Mac | `music-manager_{{version}}_x64.dmg` |

打开对应 DMG，双击“安装与更新声场档案”，点击“安装 / 更新”，等待新版启动确认后窗口会自动关闭。只有当前账户不能写入安装位置时才需要管理员授权。应用和安装器使用 ad-hoc 签名，更新包使用独立数字签名；尚未进行 Apple Developer ID 签名或公证。若 macOS 首次阻止打开，可按系统提示在“隐私与安全性”中允许该应用。
