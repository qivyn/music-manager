### v0.2.7 · 猫咪音乐角落

- 新增「奶油留白 / 月夜打盹」双主题猫咪首页、呼吸与抚摸反馈、柔和主题切换及猫咪图标。沙发进入音乐库，地毯进入最近播放，毛线球进入音乐片段。
- 优化首页试听、切歌取消、播放队列、连续保存与导入交互；波形随主题重绘，音频读取失败后可重试，不产生未处理的 Promise 拒绝。
- WAV 导出禁止覆盖原始音频，完成后原子保存，失败保留已有输出；专辑标签写入使用事务，改进标签统计和专辑移动、拆分、交换时的标签保留。
- 离线音频可继续编辑资料；微动效可关闭，并遵循系统减少动态效果偏好。

### 旧用户升级：继续使用原来的数据库

本版只替换应用，保留 `settings.json`、原 `library.db` 路径和原始音频。音乐、标签、片段、专辑标签和候选清单继续使用，无需重建音乐库或重新导入。数据库 schema 保持为 3。

- v0.2.6 用户可从设置中的检查更新入口下载并重启安装；较早版本使用下方图形化安装器。
- 旧版缺少位置配置时，选择“打开已有音乐库”，指向原 `library.db` 所在文件夹。旧默认库位于 `~/Library/Application Support/com.musicmanager.app/library.db`。
- 移动硬盘未连接或数据库缺失时等待重试，不创建替代空库。删除音乐或片段只删除记录，不删除音频。
- 更新包经过数字签名校验；安装器支持启动重试、兼容性检查后的旧版恢复和诊断信息导出。安装失败时保留原应用备份和音乐库。

### 安装

安装包使用免费的 ad-hoc（临时）签名，未进行 Apple Developer ID 签名或公证。macOS 仍可能要求首次手动允许打开。

1. 打开 DMG，双击“安装与更新声场档案”。
2. 点击“安装 / 更新”，等待窗口显示启动结果。首次安装到当前用户的“应用程序”文件夹；已有应用保持原位置，必要时系统会要求管理员授权。
3. 若 macOS 首次阻止安装器打开，请在“系统设置 → 隐私与安全性”允许打开。
4. 失败时点击“重新尝试启动”“恢复旧版”或“导出诊断信息”。请保留 DMG，后续仍可使用安装窗口。

免费临时签名不代表完成 Apple 公证；首次打开仍可能需要手动允许。

`install-macos.sh` 仅作为旧命令的兼容入口，`--replace` 会打开同一个安装窗口，不再直接删除或覆盖旧应用。旧 DMG 不含图形化入口时会停止并提示下载新版。

### 注意

- 删除音乐或片段只会移除软件中的记录，不会删除原始音频文件。
- 当前安装脚本用于小范围测试；顺畅的正式站外分发需要 Apple Developer ID 签名与公证，首次打开仍可能有普通的下载确认提示。
