### v0.2.9 · 修复应用内更新与诊断体验

- 修复 0.2.6 / 0.2.7 安装在个人“应用程序”目录时，升级因旧安装记录归档失败而中止的问题。旧记录验证后按原文保留，新安装事务使用系统目录。
- 重新排版更新窗口，清晰区分版本、更新状态、诊断结果及主要操作；安装路径和原始错误可按需展开。
- 主应用提供诊断 ZIP 导出，包含安装、交接和启动尝试日志。导出后自动在 Finder 中选中文件，并提供再次定位按钮；取消或定位失败不会覆盖原更新错误。
- 对没有导出按钮的 0.2.6 / 0.2.7，安装器会在返回更新失败前保存诊断 ZIP、在 Finder 中显示，并在旧应用中提示文件位置。
- 首次安装和更新继续统一到 `/Applications/声场档案.app`。新版启动确认成功后才清理已验证的旧副本；更新未完成时保留恢复材料。

### 从旧版升级

- **已下载但尚未安装 0.2.8**：先点击“重新检查”，下载本次 0.2.9 更新包后再安装。
- **已安装 0.2.8**：正常使用“检查更新 → 下载更新 → 重启并更新”。
- **0.2.6 / 0.2.7**：可直接检查并升级到 0.2.9，无需先安装 0.2.8。
- 更早版本没有应用内更新入口，或旧客户端因安装位置拒绝检查更新时，请下载本版 DMG，打开“安装与更新声场档案”，按提示保存并退出旧应用后继续。
- 旧位置有未完成恢复事务时，先处理恢复；不会通过删除记录绕过保护，也不会扫描全盘删除未知副本。

### 音乐库和音频保持原位

数据库 schema 保持为 3。保留原 `settings.json` 和 `library.db` 路径，音乐、片段、标签、专辑标签及候选清单无需重新导入。安装器不搬迁音乐库、不修改原始音频、不随应用恢复而回滚数据库。移动硬盘未连接时等待重试，不创建替代空库。

### 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple Silicon Mac | `music-manager_{{version}}_aarch64.dmg` |
| Intel Mac | `music-manager_{{version}}_x64.dmg` |

打开对应 DMG，双击“安装与更新声场档案”，点击“安装 / 更新”，按需完成管理员授权并等待新版启动确认。应用和安装器使用 ad-hoc 签名，更新包使用独立数字签名；尚未进行 Apple Developer ID 签名或公证。若 macOS 首次阻止打开，可按系统提示在“隐私与安全性”中允许该应用。

### 给开发者

新增独立的本地更新测试入口：在 `src-tauri` 目录运行 `cargo tauri dev --no-watch -- -- --local-update-test`，自动准备临时签名更新源、测试 App 和测试音乐库。支持正常升级、安装失败、签名失败及重置/修复场景，无需发布 Release。详见 README。
