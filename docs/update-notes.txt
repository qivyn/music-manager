v0.2.8：统一安装位置，完善更新与旧版清理。

首次安装和更新统一安装到系统“应用程序”。从旧位置升级时，确认新版启动成功后再删除已验证的旧应用副本；失败时保留必要恢复材料。不会全盘搜索或删除身份不明的应用。

安装器保留“安装 / 更新、重新尝试启动、恢复旧版、导出诊断信息”四个按钮，不再提供位置选择和历史清理入口。点击“重启并更新”后只需确认或取消；确认后忽略未保存输入，不自动保存草稿，已提交的操作会等待完成。

增加更新包兼容信息验证、可复用的已验证下载、安装事务记录、并发保护和清理重试。成功更新后清理受管旧版与安装缓存；中断时根据事务记录处理，不自动回滚数据库。

本版数据库 schema 仍为 3。继续使用原 settings.json、原音乐库路径、音乐、片段、标签和候选清单，不移动音乐库或修改原始音频。音乐库不可用时等待重试，不创建替代空库。

v0.2.6 / v0.2.7 可通过应用内更新升级；旧客户端在自定义位置无法检查更新时，请使用新版 DMG，并按提示退出旧应用。安装到系统“应用程序”可能需要管理员授权。

安装器与应用保持免费 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；macOS 首次打开仍可能需要手动允许。请按 Mac 芯片选择安装包。
